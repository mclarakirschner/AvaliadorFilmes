# Sistema de Avaliação de Filmes

Este é um projeto criado para avaliar filmes e apresenta-los em uma tabela.
O usuário pode cadastrar filmes, selecionar o gênero, atribuir uma nota de 0 à 5 e deixar um comentário se desejar. Todos os filmes adicionados são exibidos em uma tabela.
Na tabela consta as informações de cada filme cadastrado pelo usuário, em que cada linha apresenta: Nome do filme, Gênero, Nota e Comentário.
No projeto foi utilizado HTML, CSS e JavaScript.

## Funcionalidades

O projeto apresenta funcionalidades como:

- Adicionar filmes com informações de:
  - Nome do filme
  - Gênero
  - Nota de 0 à 5
  - Comentário (Opcional)

- Limpar avaliação

- Visualizar filmes em uma tabela organizada

- Possibilidade de expandir funcionalidades na tabela, como:
  - Visualizar somente os filmes do gênero selecionado
  - Visualizar somente os filmes de melhor avaliação (Nota 4 e 5)
  - Organizar a visualizacão das notas, de maior nota para menor, e de menor nota para a maior
  - Ao final da tabela, apresenta a média geral de todos os filmes cadastrados, ou se estiver filtrado, a média dos filmes do gênero selecionado.

## Tecnologias
- HTML
- CSS
- JavaScript
